# IDA Screenshot

An IDA 8-9.x plugin for capturing high-resolution screenshots of IDA widgets, windows, and full pseudocode views.

## Installation

Run `make install` (assuming you are on macOS or Linux), or place the
`screenshot.py` file in your IDA user plugins directory manually.

## Usage

Use the actions under the "Screenshot" submenu in the context menu of most
widgets, or find the `screenshot:` family of actions in the command palette.
